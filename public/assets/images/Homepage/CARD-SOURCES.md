# Homepage Suite Cards — Replace Pixelated Sources

To fix pixelated cards, **put your best originals** in this folder. Use these exact names (the script finds .jpg, .jpeg, or .png):

| Suite | Filename |
|-------|----------|
| Pénard | `suite-penard.jpg` |
| Pétanque | `Suite pétanque.jpg` |
| Bronzette | `Suite bronzette.jpg` or `.png` |
| Suite de l'Artiste | `suite de l'artiste.JPG` |

Then run:
```bash
npm run optimize-homepage-cards
```

Replace one at a time if you prefer — the script processes whatever exists.
